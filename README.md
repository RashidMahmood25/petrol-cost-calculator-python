# Petrol Cost Calculator (Python)

A simple Python practice project that estimates your monthly petrol cost.

## How to run
python petrol_cost_calculator.py

Enter your daily driving distance, the number of days you drive per month, your vehicle mileage (km per litre) and the current petrol price per litre. It prints your monthly distance, the petrol you will use, and the estimated monthly cost in PKR.

## What I practiced
Functions with multiple return values, user input and formatted output in Python.
